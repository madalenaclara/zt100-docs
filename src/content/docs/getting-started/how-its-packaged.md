Zero to 100 is modular. A client does not have to buy everything at once. They can start with a single capability, take one stage of the journey, or run the whole thing. Each part delivers value on its own and leads naturally to the next, so an account can grow over time instead of being one large, all-or-nothing decision.

## The buyable units

Each stage of the [journey](/getting-started/the-journey/) can be bought on its own, and the capabilities inside a stage are available individually too.

| You can buy | What is included | Often used to |
|---|---|---|
| **See where you stand** | AI Maturity Assessment, Insights dashboard, Risk & Compliance, Browser extension | Open the relationship with a quick, low-commitment diagnostic |
| **Build the capability** | Courses, AI Lab, Community | Close the gaps the diagnostic finds, with training and practice |
| **Workflows & AI assistants** | Workflow analysis and assistant builder, AI Use Cases | Turn real tasks into working assistants and size the automatable hours |
| **Private AI** | Connected AI, Meetings, Drive, Workflows Studio, private deployment and controls | Run AI on sensitive data inside the client's own environment |
| **Agents & automation** | Internal AI tools, autonomous agents, document handling and on-device AI | Build and run custom automation as a project |
| **The whole journey** | All of the above, connected | Run a complete AI programme end to end |

## Common ways to start

- **Start small.** Just the diagnostic. It is quick, low-commitment, and easy to agree to, and it makes the case for what comes next.
- **Go broad.** The full platform: diagnostics, learning and workflows together, for an organisation that wants to move on all fronts.
- **Go secure.** Add Private AI for sensitive or regulated work that cannot use public tools.
- **Go custom.** Agents and automation built around a specific bottleneck, delivered as a project.

You can combine these in any order. A common path is to start with the assessment, add learning and a first set of assistants, then expand into Private AI or automation where it pays off, and re-assess to show the progress.

## Good to know
The journey is the recommended path, because each stage reinforces the others and the value compounds. It is not a requirement. Final scope and pricing are set with your Zero to 100 contact.
