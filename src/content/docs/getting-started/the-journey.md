The platform runs as one journey, in three stages. Used together they form a loop: see where people stand, build the capability, put AI to work, then measure again. Because it is a loop, you show measurable progress over time, not a single snapshot.

![The loop: see where you stand, build the capability, put AI to work, then re-assess to track progress.](/images/journey-loop.svg)
_Each stage feeds the next, and re-assessing closes the loop._

## The three stages
1. **See where you stand**: measure where every person and team stands today, and make real AI usage visible.
2. **Build the capability**: close the gaps with training and deliberate practice, and keep the organisation current.
3. **Put AI to work**: turn daily work into assistants and agents, deployed and run securely.

Then re-assess, and the loop repeats.

## It is modular
Each stage stands alone. A client can start with one, add the rest later, or run the whole journey. Most start with the assessment, because it is quick and low-commitment, then expand from there. See [how it is packaged](/getting-started/how-its-packaged/).

## Why a loop matters
- Improvement is measurable: each person sees how they have changed since the last result, and leaders see the whole organisation move.
- Nothing is a dead end: an assessment points to the right training, training surfaces real tasks to build, and built assistants become candidates for deployment.
- The picture stays current. Because the tools change constantly, a single snapshot ages fast, a loop does not.

## Good to know
A partner runs the loop with the client: they read the diagnostics, assign the learning, scope the build and automation work, and re-assess to prove the progress.
