A hands-on space where people practise and build, separate from the courses. It is where a skill becomes real work before anything is rolled out.

![The AI Lab: Prompt Library, Prompt Arena, Workflow Challenge and Build Studio (demo data).](/images/ai-lab.svg)
_Four hands-on tools that turn training into real, tested work (demo data)._

## What's inside
- **Prompt Library**: prompts that already work, ready to reuse.
- **Prompt Arena**: compare different approaches to the same task, side by side.
- **Workflow Challenge**: practise on real cases to build confidence.
- **Build Studio**: build and test an assistant or prototype safely before deploying.

## Good to know
The AI Lab is what turns training into adoption, and it surfaces the concrete use cases that become build and automation projects.
